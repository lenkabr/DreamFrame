# DreamFrame

DreamFrame is a work-in-progress prototype for discovering one thoughtfully matched film based on your mood, desired emotional outcome, or favorite movies.

The goal is to replace endless browsing with one confident, personal recommendation—and explain why that film fits the moment.

## Prototype status

The current version demonstrates the interaction and visual direction with a small curated local movie set. Live TMDB poster data and LLM-powered recommendation logic are planned next.

## Run locally

```bash
npm install
npm run dev
```
